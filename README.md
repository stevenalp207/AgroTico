# AgroTico Smart 🌱

> Innovación costarricense que transforma el campo

## 📋 Descripción

AgroTico Smart es una plataforma integral de agricultura de precisión desarrollada por estudiantes del Colegio Técnico Profesional Don Bosco en Costa Rica. Combinamos **IoT, inteligencia artificial y datos satelitales** para ayudar a los agricultores a tomar decisiones informadas y mejorar sus cultivos.

### ✨ Características Principales

- 🎯 **Dashboard Inteligente**: Visualización de datos agrícolas en tiempo real
- 🔓 **Código Abierto**: Todo nuestro software es open source
- 🖨️ **Diseños 3D Abiertos**: Piezas imprimibles y adaptables
- 📚 **Capacitaciones**: Talleres y recursos educativos
- 🌍 **Sostenibilidad**: Fomenta una agricultura más responsable

## 🚀 Inicio Rápido

### Prerrequisitos

- Node.js 18+ o superior
- npm o pnpm

### Instalación

```bash
# Clonar el repositorio
git clone https://github.com/stevenalp207/AgroTico.git
cd AgroTico

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

El sitio estará disponible en `http://localhost:4321`

## 🛠️ Scripts Disponibles

```bash
npm run dev       # Inicia servidor de desarrollo
npm run build     # Construye para producción
npm run preview   # Vista previa de la build
```

## 📁 Estructura del Proyecto

```
/
├── public/           # Archivos estáticos
├── src/
│   ├── assets/      # Imágenes, CSS, y recursos
│   ├── components/  # Componentes Astro reutilizables
│   ├── data/        # Archivos JSON con contenido
│   ├── layouts/     # Layouts de página
│   └── pages/       # Páginas del sitio
├── astro.config.mjs # Configuración de Astro

```
